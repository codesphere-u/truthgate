Deterministic Rules (TG001–TG008)

Filter citation entailment checks and workspace AST symbol rules.

Code Category Severity Verdict & Check
TG001entailmentCRITICALPhantom Source Citation (PHANTOM_CITATION)
Claim cites a [source_id] that does not exist in the provided context corpus.
TG002entailmentHIGHLow Lexical/Entity Support (UNVERIFIED)
IDF-weighted content-token and technical-entity overlap between claim and cited source falls below threshold.
TG003entailmentCRITICALNegation Polarity Inversion (CONTRADICTED)
High entity/predicate overlap with a source sentence, but opposite negation or antonym polarity (enabled/disabled, permitted/prohibited).
TG004entailmentCRITICALNumeric & Magnitude Drift (NUMERIC_DRIFT)
Claim introduces a number, percentage, or currency quantity (ms, USD, UGX, %) that mismatches the cited source.
TG005entailmentMEDIUMUncited Factual Assertion (UNVERIFIED)
Factual or numeric proposition in strict-grounding mode lacks any supporting source citation or workspace evidence.
TG006workspace_groundingCRITICALNon-Existent File Path (BROKEN_CODE_REF)
Referenced file path does not exist inside the configured workspace root or attempts path traversal.
TG007workspace_groundingHIGHOut-of-Bounds Line Range (BROKEN_CODE_REF)
Referenced line range (#Lstart-Lend) exceeds the actual line count of the workspace file.
TG008workspace_groundingCRITICALPhantom Code Symbol (BROKEN_CODE_REF)
Referenced function, class, or method symbol does not exist in the file's Python AST or TS/JS/Go/Rust symbol table.
