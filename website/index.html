Frequently Asked Questions

Why use TruthGate instead of an LLM-as-a-Judge guardrail?

LLM judges add 1–3 seconds of latency, extra API cost, and stochastic variance. TruthGate audits citations, negation flips, numeric drift, and AST symbols deterministically in 0.128 ms P50 with 100.0% precision and recall on its 40-scenario benchmark.

What rules does TruthGate check across text and code?

TG001–TG005 check phantom source IDs, IDF-weighted entity support, negation/antonym polarity inversions, numeric/currency drift, and uncited factual assertions. TG006–TG008 ground file paths, #Lstart-Lend ranges, and AST symbols.

Does TruthGate work as an MCP Server and HTTP Workbench?

Yes. Run truthgate mcp for Stdio JSON-RPC 2.0 MCP or truthgate serve-http for Streamable HTTP/SSE MCP, REST endpoints, Prometheus metrics, and the Workbench UI.
